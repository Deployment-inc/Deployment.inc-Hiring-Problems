# Private submissions

This directory contains instructions only. Do not add candidate YAML, repository links, code,
methods, experiments or results to this public repository.

Create a separate private solution repository and share it only with the designated reviewers in
[CONTACT.md](../CONTACT.md). Send `submission.yaml` privately using that route, following
[SUBMISSION_SCHEMA.md](../SUBMISSION_SCHEMA.md). Do not fork this board to submit your solution.

A reviewer returns a private submission ID. Resubmit or withdraw through the same private thread;
resubmissions must identify the new exact commit SHA. One active submission per person per problem.
